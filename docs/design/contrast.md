# Contrast ratios of the design tokens

Generated by `npm run contrast -w @repr-werkbank/web` from `packages/web/src/tokens.ts`; do not edit by hand.
Ratio = (L1 + 0.05) / (L2 + 0.05) with the WCAG 2.x relative luminance of sRGB (`packages/web/src/contrast.ts`).
`test/contrast.test.ts` fails when a text pair is below 4.5 (WCAG 1.4.3, AA) or a border/focus/symbol pair is below 3 (WCAG 1.4.11, AA).
The hairline colour `line` separates zones and is decorative; it is exempt.
