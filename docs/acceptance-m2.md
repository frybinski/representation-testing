# Acceptance of milestone M2: which test proves which point

Section 8 of `Planung.md` lists eight points for M2. Commands run in the repository root. `npm run e2e` builds everything, serves the built page
on a free port and drives Chromium (`vitest.e2e.config.ts`, files in `packages/web/e2e/`); it is not part of `npm test`. Chromium comes from
Playwright, else from `PW_CHROMIUM_EXECUTABLE`, else from `/opt/pw-browsers/chromium`; CI installs it with `npx playwright install --with-deps chromium`.
Firefox and Safari are not tested (NF-03; see the M2 report in `HANDOVER.md`).
