# Example models

All models in this directory were written by hand for this project (the three
larger workflow nets partly generated by a throwaway script that is not part of
the repository, see below). They are not copied from any third-party model
collection. They are licensed under CC BY 4.0 (see `LICENSE` in this directory),
Copyright (c) 2026 Fabian Rybinski (rights holder to be confirmed, see H3 in
`HANDOVER.md`).

Every file is read by the parser without any notice; `packages/core/test/examples.test.ts`
enforces that, validates the resulting model against `docs/model.schema.json` and
checks that reading twice gives the same model. Files that are deliberately
broken or contain unsupported elements live in `packages/core/test/fixtures/`.

## Workflow nets for the soundness check (Stage C)

A workflow net has one source place `i` (the only place with an initial token) and one sink place `o`. Soundness means: from every reachable marking the final marking (one token in `o`, nothing else) is reachable, the final marking is the only marking with a token in `o`, and every transition can fire in some reachable marking.

**The arguments below were derived by hand. They are NOT yet machine-checked.** Stage C has to verify them with the soundness checker and fix the state bound; this directory does not decide that bound.

| File | Property | Reason (by hand) |
| --- | --- | --- |
| `pnml/wf-sound.pnml` | sound | `register` moves the token to `p_reg`; `split` is an AND split into `p_rev0` and `p_cred0`; `review` and `credit` each fire exactly once on their branch; `join` consumes both branch results and produces one token in `p_ready`; `finish` moves it to `o`. Every reachable marking is a legal interleaving of the two branches and can be completed. No transition is dead. The net is 1-bounded. 8 places, 6 transitions. |
| `pnml/wf-deadlock.pnml` | contains a deadlock | `choose_left` and `choose_right` are in conflict over the token in `i` (XOR split) but `join` needs a token in both `a` and `b` (AND join). After `choose_left` the marking is `a=1`, no transition is enabled, and `o` is empty: a reachable dead marking that is not the final marking. Hence not sound. 4 places, 3 transitions. |
| `pnml/wf-large.pnml` | state space far beyond any reasonable bound | `split` puts a token into each of 20 independent branches; each branch is a chain of 5 transitions (6 places `q<b>_0 … q<b>_5`); `join` needs a token in all 20 end places. The branches are independent, so the marking of each branch is one of 6 positions and the reachable markings after `split` number 6^20 = 3 656 158 440 062 976, plus `i` and the final marking. The net is sound by the same argument as `wf-sound.pnml` (AND split, independent chains, AND join), so only the size, not the verdict, is the point. 122 places, 102 transitions, 242 arcs. The file was generated by a throwaway script (ids `q<b>_<k>`, `t<b>_<k>`) and is not intended to be read by humans. |
